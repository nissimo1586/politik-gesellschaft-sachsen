Politik & Gesellschaft – Sachsen

Abonnierbare Kalender für politische, gesellschaftskritische und wissenschaftliche Veranstaltungen in Sachsen. Die Erfassung wird derzeit schrittweise automatisiert; nicht alle Quellen sind bereits maschinell auswertbar.

Kalender abonnieren

  • Ganz Sachsen (ICS)
  • Chemnitz (ICS)
  • Leipzig (ICS)
  • Dresden (ICS)

Im Kalenderprogramm bitte per Internetadresse abonnieren, nicht die Datei einmalig importieren. Der Kalender kann unvollständig sein. Maßgeblich sind die Veranstalterseiten.

Die automatische Aktualisierung wird über GitHub Actions vorbereitet. Ob der Workflow erfolgreich läuft, ist im Repository unter Actions sichtbar.
